# Модель расчёта PRICING_REVIEW.md

Внутренняя аналитика, не часть сайта и не деплоится. Папка в `.gitignore`.

Запуск (Python 3, без зависимостей):

    python3 scripts/pricing-model/build.py     # пересобирает /PRICING_REVIEW.md из template.md + расчётов

Файлы:
- `calc.py` — исходные допущения: manual-часы по 11 этапам, доли сжатия (текущая и mature), буферы, текущие цены. **Правьте здесь.** `python3 calc.py > output.txt` печатает сводную таблицу.
- `gen.py` — рейтинги, предлагаемые цены, ожидания клиента (lag). `python3 gen.py > output-sanity.txt`.
- `catalog_data.py` — снимок состава/ограничений/опций из `site/src/data/products.ts` (при изменении каталога обновлять вручную).
- `build.py` + `template.md` — генерация таблиц и подстановка в текст документа (`@@T1@@` и т. п.).
- `output.txt`, `output-sanity.txt`, `data.json` — результаты последнего запуска.

Все часы — оценки по составу работ, не замеры. Цены каталога здесь скопированы, а не читаются из `products.ts`.
