## Зачем этот разбор

Сайт 3D Studio — не только витрина, но и рабочий пример нашего подхода: быстро, прозрачно, без тяжёлых систем там, где они не нужны.

## Стек

Основа — Astro SSG. Главная и внутренние страницы собираются в статический HTML, а интерактив подключается только там, где он нужен: в брифе.

Контент лежит в markdown. Это проще поддерживать на старте: кейсы, продукты и материалы Лаборатории проходят через сборку, а не живут в отдельной админке ради пары страниц.

## После git push

Маршрут релиза будет одинаковым: git push → сборка → проверка → деплой → ночной бэкап.

Такой маршрут важен не сам по себе. Он снижает риск случайного релиза и даёт повторяемость: если страница сломалась, это видно до публикации.
