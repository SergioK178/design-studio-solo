## 1. Принципы

- Сайт студии собирается на инженерной культуре, которую мы продаём:
  скорость, декларативность, честные метрики. Стек при этом минимальный —
  сервис добавляется только когда без него больно, а не «на вырост».
- Всё селфхост, опенсорс, без подписок. Данные (заявки, аналитика) — на
  нашем сервере в РФ (аргумент 152-ФЗ в продажах).
- Один дешёвый VPS (1–2 ГБ RAM). Деньги не жжём на оперативку ради
  сервисов с малой отдачей; что вернётся и когда — см. §9.
- Сервер описан декларативно (Ansible); systemd — единственный оркестратор.

## 2. Стек

| Слой | Выбор | Примечание |
|---|---|---|
| Фронт | Astro | Статика + острова; JS только там, где интерактив (бриф, метрики) |
| Стили | Tailwind CSS | Токены из spec.md §10 → tailwind-конфиг |
| Островки | Svelte | Бриф, живые метрики; минимальный рантайм |
| Контент | Astro content collections | Кейсы, лаборатория, продукты — markdown в репо |
| Динамика | Мини-API (один сервис) | Черновики брифа, метрики, amoCRM, Telegram |
| БД | SQLite | Один файл: brief_drafts + история метрик |
| Аналитика | GoatCounter | Один Go-бинарник + SQLite, скрипт <4 КБ, UTM видно |
| Ошибки | journald + логи Caddy | На клиенте опционально window.onerror → мини-API |
| Веб-сервер | Caddy | Авто-TLS, статика + reverse proxy |
| Оркестрация | Podman + Quadlet | Rootless-контейнеры как systemd-юниты, auto-update |
| IaC | Ansible | Одна машина; OpenTofu вернётся, когда машин станет >1 |
| Бэкапы | Крон: sqlite3 .backup + rclone на внешнее хранилище | Ночной; восстановление проверить один раз при настройке |
| Мониторинг | Внешний аптайм-пинг (бесплатный сервис / домашняя машина) | Uptime Kuma — бэклог 1.5 вместе с поддержкой |
| Хостинг | 1 VPS в РФ (Selectel/Timeweb и т.п.) | Минимальный тариф, 1–2 ГБ RAM |

## 3. Архитектура (v1)

```
[Браузер]
   │
   ▼
[Caddy (авто-TLS)]
   ├── статика Astro (SSG; островки: бриф, метрики)
   ├── /api/*      → мини-API (брифы, метрики, amoCRM, TG)
   └── /count/*    → GoatCounter
        │
   [SQLite (файлы на диске)]
```

- Сайт — SSG: контент собирается из markdown на билде; правка контента =
  коммит в main = деплой.
- Динамика — два клиентских островка (Svelte) + мини-API.
- GoatCounter и мини-API — quadlet-юниты; наружу торчит только Caddy.
- Оценка RAM: Caddy ~30 МБ + мини-API ~80 МБ + GoatCounter ~30 МБ —
  четырёхкратный запас даже на 1 ГБ.

## 4. Умный бриф — техническая часть

- Островок Svelte в Astro; состояние шагов — на клиенте.
- Черновик: POST в мини-API → таблица `brief_drafts` (id-ссылка,
  JSON ответов, TTL 60 дней).
- Оценка (вилка цены/срока) считается **на клиенте** по матрице
  коэффициентов из JSON-файла в репо (правка = коммит, релиз за минуты).
- Сабмит: мини-API → amoCRM API (сделка + поля) → Telegram Bot API
  (уведомление). Токены — в env на сервере, фронт их не видит.
- Антиспам: honeypot + время заполнения; капчу не ставим (трение),
  пересмотрим при реальном спаме.
- Деградация без JS: обычная POST-форма с теми же полями одним экраном.

## 5. Живые метрики

- CI-джоба после каждого деплоя: Lighthouse CI (headless) + замер TTFB/веса →
  POST в мини-API → SQLite. Крон-прогон раз в сутки (метрики не «протухают»
  без релизов).
- Мини-API отдаёт JSON (кэш 10 мин); фронт рисует цифры из API.
- При недоступности API секция показывает последние сохранённые значения
  с пометкой даты — никаких хардкодов.

## 6. CI/CD

- Репозиторий: monorepo (astro + мини-API + ansible + quadlet-юниты).
- Всё сразу в main, без веток и PR (spec.md §9).
- push в main → CI: линт (eslint, prettier), typecheck, сборка →
  деплой (rsync статики + podman auto-update мини-API) →
  Lighthouse-джоба → результат в мини-API + уведомление в TG.
- Перед пушем локально: сборка проходит, /code-review для крупных кусков.

## 7. Безопасность и ПД

- Заявки и черновики брифов = персональные данные: хранение в нашей БД в РФ,
  политика на /legal/, согласие чекбоксом, TTL черновиков — 60 дней.
- Секреты — не в репозитории: sops/age, на сервере — env-файлы
  с правами 600 / systemd credentials.
- SSH — по ключам, fail2ban, unattended-upgrades.
- Админки наружу не торчат: GoatCounter-админка — за basic auth Caddy
  или через SSH-туннель.
- Бэкап-копия SQLite шифруется перед выгрузкой (age), ключ — вне сервера.

## 8. Бюджеты производительности (контракт со spec.md §10)

- Главная: ≤ 300 КБ transfer без шрифтов; шрифты — woff2 subset (латиница
  урезана до используемого, кириллица полная), ≤ 120 КБ суммарно.
- JS на главной: только островки; ориентир ≤ 70 КБ gzip.
- LCP ≤ 1.5s на Moto G Power-классе, CLS ≈ 0.
- Эти цифры публикуются на сайте — они и есть маркетинг, срыв бюджета =
  срыв продукта.

## 9. Что вернётся в стек и когда

| Сервис | Когда возвращается | Триггер |
|---|---|---|
| Uptime Kuma + публичная панель | Фаза 1.5 | Начинаем продавать поддержку-подписку |
| Полноценные бэкапы (restic, вторая площадка) | Фаза 1.5 | Появляются клиентские данные на поддержке |
| Directus + PostgreSQL | Фаза 2 | Кабинет клиента: контент правят не-разработчики |
| MinIO | Фаза 2 | Файлы клиентов в кабинете |
| n8n | Фаза 2 | Флоу становятся многочисленными и клиентскими |
| Второй VPS | Фаза 1.5–2 | Мониторинг + приём бэкапов с первой машины |
