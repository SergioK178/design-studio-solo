# Логика умного брифа v1

Фаза 3 считает только предварительную вилку на клиенте. Это ориентир, не оферта: точная цена фиксируется после проверки задачи и договора.

## Вопросы

1. Что нужно собрать.
2. Есть ли контент.
3. Есть ли дизайн или бренд.
4. Нужны ли интеграции.
5. Насколько срочно.
6. Какой бюджет комфортен.

## Модель оценки

Тип проекта задаёт базовую вилку цены и срока. Остальные ответы корректируют вилку:

- контент не готов → добавляет время и бюджет;
- нужен кастомный дизайн → добавляет бюджет;
- CRM/API/данные → добавляют бюджет и срок;
- срочный запуск → сужает срок, но повышает нижнюю границу;
- бюджет не режет оценку, а помогает выбрать формулировку результата.

## Граница фаз

В Phase 3 черновик хранится в URL, а Telegram-ссылка получает summary ответов. Серверное сохранение, POST fallback, панель заявок и уведомления появляются в Phase 4.
